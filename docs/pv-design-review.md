# 作品PVの構成と検証

2026-11-05。説明付きの「まにあう」サンプルの承認を受け、8作品すべてを同じ構成で仕上げました。人物・駅の描き直しを引き継ぎ、利用する場面、入力、処理、結果が自然な説明文と映像で分かるようにしています。前版は `726ebea8ea4a5f355efbfae11cd4565d08d352f8` です。

## 構成

- 概要・作成記録：約12秒。入力、アプリの処理、結果を3場面で説明します。各場面を約4秒とし、短く平易な説明文を映像内と下の説明欄に表示します。オリジナルSVGとCSSで再生し、MP4をダウンロードしません。
- 詳細：約30秒。利用場面4秒、ねらい4秒、操作4秒、体験4秒、特徴5秒、結果5秒、機能のまとめ4秒。場面切り替え、見出しの登場、絵の動きと実装に即した操作の再現を組み合わせます。
- 「まにあう」は外出前の人と駅から始め、位置情報、駅入口までの徒歩時間、余裕時間、乗車できる列車と出発時刻の目安を見せます。駅名看板・改札・ホーム・線路・電車を描き、一目で駅と分かるようにしました。
- しゅうかつ手帳は散らばった締切の整理、Streaming Screenは配信画面を作る体験、Yomiage Botは声を出せない場面の会話参加、Shindo Botは普段のDiscordで通知を受け取る場面から紹介します。
- 研究・開発作品は目的と対象範囲を伝え、Artificial Moral ArchitectureのCLI、Inspection Proxyの転送後検出、SSL Robot AIの個人用2D環境という実装上の区別を保ちます。

## 再生

通常は画面内で自動再生し、閲覧者が一時停止・再開できます。MP4は消音・インライン・ループです。画面外やバックグラウンドでは停止し、閲覧者が止めた場合はスクロールで再開しません。ブラウザに自動再生を拒否された場合は再生ボタンから始められます。

「動きを減らす」設定では自動で動かさず、結果の静止画を表示します。再生ボタンを押すと動きを確認できます。外側の説明文は映像内の小さな文字を読まなくても内容を追えるようにし、PVの範囲と架空データの注記を付けています。

参照した8作品のコミット・実装箇所・計算例・実接続を検証していない範囲は [feature-flow-evidence.md](feature-flow-evidence.md) に記録しています。人物や利用場面は演出、データと画面は説明用の再現です。実録、現地GPS計測、実際の災害速報、実機ロボットの成績としては示しません。翻訳から自動読み上げへの連結、保存前のOBS出力、本文の送信前DLPなど、確認できない機能を追加していません。

## 再生成・検証

`video/recreations/product-pv.tsx` と `site/music/product-pv.js` が現行入口です。`REMOTION_BROWSER_EXECUTABLE` にChromium系ブラウザのパスを指定し、`node video/recreations/render.mjs` で詳細PVを生成します。`ONLY=mania` などで作品を限定でき、`FORMAT=short` では確認用の12秒MP4を `.review/pv-short-media/` に出力します。サイトの短いPVはこのMP4を読み込みません。

`npm run build`、`review-core-demos.mjs`、`review-book-overview.mjs`、`review-flow-films.mjs`、`review-pv-controls.mjs`、`verify-flows.mjs` の結果は `.review/` に保存します。PC・スマホはEdgeの画面幅とタッチのエミュレーションで確認し、iPhone実機やSafariでの検証はしていません。
