## 表示と文章

トップは「誰の課題を解決するかを考え、プロダクトをつくる。」「PdMを目指し、個人開発・個人研究に取り組んでいます。課題設定から設計・実装まで、自分で手を動かして確かめています。」としました。

詳細では色付きの設計・振り返り欄と、本文として読める仕組み図を追加しました。まにあうでは、UI案を見せて必要な情報を聞いたこと、慣れた経路と慣れない出発地点の違い、発車時刻を先にする理由、既存の乗換案内で十分な人も多かった学びを説明しています。20人近くという人数を、継続利用率や課題解決の証明には置き換えていません。

リポジトリ作成記録から作品画像を削除し、8作品に作った理由または結果を追加しました。年月のJST処理、右タブと左本文、ページ右端の折り返しは維持しています。既存の検索の本の飛行、付箋の剥がれ・再貼付、無音、詳細動画も維持しました。動画ファイルの差分はありません。
