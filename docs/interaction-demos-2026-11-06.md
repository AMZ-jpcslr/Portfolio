# 8作品の操作再現アニメーション

2026年11月6日。実画面録画案から、**実際の操作と結果を同じ順序で示すUIアニメーション**へ変更しました。初回はローカルで完成・検証し、その後ユーザーからGitHubへのプッシュ許可を受けました。

## 映像の方針

- 8作品すべて、アプリ・Discord・端末・2Dシミュレーターの画面を簡略再現。
- 利用場面の導入、人物の挿絵、説明テロップ、ナレーション、機能のまとめ画面を追加しません。
- 映像内の文字はアプリのラベル、サンプル入力、Botの応答、CLIの出力など、操作画面に必要な内容です。
- 概要・作成記録は約8秒。詳細は20〜22秒。同じ操作順を使い、短尺版は早送りしています。
- 自動再生・消音・ループ・任意停止を維持。スクロール後も手動停止を保持し、画面外・バックグラウンド・モーダルの裏では停止。動きを減らす設定では手動再生。
- 再現であること、架空データ、実接続していない範囲を動画の外に明記します。録画や実サービスの稼働証明とは表現しません。
